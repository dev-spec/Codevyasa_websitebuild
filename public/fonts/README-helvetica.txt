Helvetica Now Display — home page font
======================================

The home page ("/") is set to use "Helvetica Now Display".

IMPORTANT: Helvetica Now Display is a LICENSED font from Monotype. It is NOT a
free/open font, so it cannot be downloaded automatically. To show the real font
to every visitor, you must supply the font files you are licensed to web-embed.

Right now (no files yet): the home page falls back to the nearest system
Helvetica — Helvetica Neue on Mac, Arial on Windows — so it already reads as a
clean Helvetica-style page rather than the previous Clash Display headings.

TO SELF-HOST THE REAL FONT (recommended for the live site)
----------------------------------------------------------
1. From your Monotype/licence, get the WEB font files (.woff2 preferred).
   You typically want a few weights, e.g.:
      HelveticaNowDisplay-Regular.woff2
      HelveticaNowDisplay-Medium.woff2
      HelveticaNowDisplay-Bold.woff2
2. Drop those .woff2 files into this folder (public/fonts/).
3. Tell me the exact file names — I'll register them with next/font/local
   under the family name "Helvetica Now Display", and the home page will use
   them automatically for all visitors (no other change needed).

Note: .otf/.ttf also work but .woff2 is much smaller/faster for the web.
